\# Phase 2 — Git Skills Check



\* \*\*`git restore`\*\*

&#x20; Undos any local edits you have made since last commit and resets file back to last saved state.



\* \*\*`git reset --soft`\*\*

&#x20; Moves repo back to older commit but leaves all code changes intact.



\* \*\*`git reset --hard`\*\*

&#x20; Destructive command that moved back to older commit and permanently deletes all work and commits after that point.



\* \*\*`git revert`\*\*

&#x20; Safe way to undo commit. Instead of deleting history, it creates brand new commit that does exact opposite of the bad commit which neutralizes it without messing up anyone else's history.
